Cara main

Empat langkah ke panggung

Baru pertama kali? Pilih TUTORIAL di menu Home untuk latihan singkat sekitar 1 menit.

  1. 01

    Pilih role dan level

    Pilih BEAT, HARMONY, atau LEAD, lalu pilih level Easy, Medium, atau Hard.

  2. 02

    Tekan tepat di ketukan

    Setelah hitung mundur 3, 2, 1, GO, note jatuh di lane kamu. Tekan saat note menyentuh garis, dan tahan untuk hold note.

    → Note sampai di garis, tekan tombolnya.

  3. 03

    Jaga band tetap kompak

    Perfect +5 poin, Good +3, Miss 0. Combo dan Band Energy naik kalau kamu konsisten. Di ketukan Unison, semua role harus Perfect untuk bonus Band Energy.

    Dapatkan rank

    Rank dihitung dari akurasi. Kamu juga dapat koin untuk dipakai di Store.

Mode main

Sendiri atau bareng teman

Solo

Kamu pegang satu role, dua role lainnya dimainkan COM. Bisa pause dengan Esc.

Multiplayer LAN

Sampai 3 pemain di jaringan Wi-Fi atau LAN yang sama. Host membuat room, pemain lain bergabung lewat pencarian otomatis atau alamat IP. Tiap pemain memilih role di lobby, role kosong diisi COM, dan skor tim sama untuk semua.

FAQ

Pertanyaan yang sering muncul

Berapa harganya?

Gratis. Item di Store dibeli dengan koin hasil bermain, bukan uang sungguhan.

Di mana download-nya?

Di itch.io: tutu13.itch.io/beatlock. Ekstrak semua isi file zip, lalu jalankan Beatlock.exe. Jangan pisahkan Beatlock.exe dari Beatlock.pck.

Windows memunculkan peringatan saat dibuka?

Wajar, karena game belum ditandatangani secara digital. Klik More info, lalu Run anyway.

Jalan di perangkat apa?

PC Windows 64-bit dengan keyboard, butuh sekitar 130 MB ruang disk. Game ini ringan: sudah berjalan lancar di laptop dengan grafis bawaan Intel HD Graphics 520.

Bisa dimainkan di browser atau HP?

Belum. Beatlock adalah game PC.

Harus main bertiga?

Tidak. Mode Solo bisa dimainkan sendiri, role lain dimainkan COM.

Bisa main online lewat internet?

Saat ini hanya LAN, artinya semua pemain di jaringan yang sama.

Multiplayer LAN tidak tersambung?

Pastikan semua PC di Wi-Fi atau LAN yang sama dan memakai versi game yang sama. Saat Windows Firewall bertanya, izinkan Beatlock di Private networks (game memakai port UDP 24680 dan 24681).

Main pakai apa?

Keyboard. Tombol tiap role bisa diatur di Settings.
